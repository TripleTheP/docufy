# PDF-Modus (aus PdfCraft übernommen)

Dieses Verzeichnis enthält den Code von [PdfCraft](https://github.com/storytold/pdfcraft)
(Revision `c735fb7da55264e7cd84eed0688ec0cec5e628d4`), übernommen unter MIT OR Apache-2.0.
Die Hinweise des Originals stehen in [NOTICE](NOTICE), die Herkunft jeder Datei in
[ATTRIBUTION.md](ATTRIBUTION.md).

- `crates/` – PDF-Bibliotheken und -Oberfläche
- `vendor/` – von PdfCraft gepatchte Drittanbieter-Crates (hayro, lopdf, vello); siehe `vendor/README.md`
- `assets/` – Schriften und Icons der PDF-Oberfläche

Änderungen gegenüber PdfCraft sind in der Git-Historie von Docufy nachvollziehbar.
